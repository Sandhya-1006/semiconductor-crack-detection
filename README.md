
# Industry 4.0 AI-Based Smart Semiconductor Crack Detection and Inspection System

## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify semiconductor images into Crack and No Crack categories. A Streamlit dashboard allows users to upload images and view prediction results.

## Technologies Used
- Python
- TensorFlow
- Keras
- CNN (Deep Learning)
- Streamlit
- NumPy
- Pillow

## Key Features
- Semiconductor image upload
- Image preprocessing
- Automated crack classification
- Prediction score and confidence display
- Interactive dark-themed dashboard

## Model Performance
- Training Accuracy: 99.05%
- Validation Accuracy: 99.57%

## How It Works
1. Upload a semiconductor wafer image.
2. The image is resized and preprocessed.
3. The trained CNN analyzes the image.
4. The dashboard displays Crack or No Crack with prediction information.

## Project Purpose
To demonstrate AI-based image classification for semiconductor inspection and support automated visual quality checking.
